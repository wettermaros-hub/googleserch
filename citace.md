## Použití AI

Při tvorbě kódu byl použit tento prompt od zadavatele:

> Vytvořte web dle zadání CS50 Harvard Web Projects 0: Search. Web má obsahovat hlavní Google Search, Google Image Search a Advanced Search, navzájem propojené stránky, funkční odesílání hledání a tlačítko „I'm Feeling Lucky“. Přidejte také samostatnou stránku s co největším množstvím typů formulářových prvků, odkazy na validaci HTML a CSS pro každou stránku, odkaz na tento soubor s citacemi a zdroji a odkaz na moje portfolio.

AI pomohla s návrhem struktury HTML, českými texty, CSS vzhledem a kontrolním seznamem požadavků. Výsledný kód a odkazy je potřeba před odevzdáním zkontrolovat.
